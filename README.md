# To-do-list

Программа `To-do-list` является шаблоном для списка заметок, который можно интегрировать на сайт или web-приложение.

## Как проверить

Перед началом работы с проектом необходимо установить `Node.js v22.21.1`. 

После этого необходимо добраться до корневой папки проектоа в консоли и написать следующее:
```
npm start
```

## Как редактировать

`App.js` - корневая компонента проекта, объединяющая все его составляющие.

`index.css` - файл стилей проекта.

`components/NewToDoForm.jsx` - компонета, которая отвечает за элемент, вводимый пользователем и в последующем добавляемый в список.

`components/ToDoList.jsx` - компонента отрисовки списка.

`components/ToDoItem.jsx` - компонента, содежащая каждый элемент списка, с которыми можно взаимодействовать различным образом.

## Цель проекта

Проект был написан в образовательных целях в процессе занятий в школе "Третье место"
